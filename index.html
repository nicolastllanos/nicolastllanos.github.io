Caso de Estudio Destacado

Retail Analytics Pipeline (Big Data)

Análisis distribuido de +1 Millón de transacciones comerciales para segmentación inteligente.

1. Breve descripción de la tarea

Construir un pipeline ETL distribuido con PySpark para procesar +1M de transacciones históricas de retail, aplicar limpieza y agregaciones, y entrenar modelos de segmentación.

2. Desafío principal

El volumen de datos excedía la capacidad de procesamiento en memoria con herramientas como pandas, generando cuellos de botella que impedían extraer valor analítico.

3. Solución propuesta

Migrar el procesamiento a PySpark con DataFrames distribuidos y Spark SQL. Implementé scripts modulares para limpieza, transformación y clustering de clientes según patrones de consumo.

4. Herramienta técnica utilizada

Apache Spark (PySpark) como motor de cálculo distribuido, Spark SQL para consultas columnares eficientes, y Spark MLlib para entrenar modelos de Machine Learning (K-Means / Regresión Logística).

5. Principales aprendizajes

Aprendí la importancia del particionamiento de datos, la serialización en formato Parquet para eficiencia de lectura, y cómo configurar sesiones Spark para optimizar memoria.

6. Métricas de impacto

El pipeline procesó más de 1.000.000 de registros sin saturación de memoria, generando datasets limpios y reportes exportados para análisis posterior.

7. Habilidades técnicas aplicadas

Ingeniería de Datos (ETL Distribuido), Manipulación Avanzada SQL, Modelado Predictivo No Supervisado, Configuración de Sesiones Spark, y estructuración de código modular OOP en Python.

8. Justificación de elección

Elegí este proyecto porque demuestra mi capacidad para construir pipelines escalables, trabajar con datos masivos y conectar procesamiento distribuido con análisis de negocio.
